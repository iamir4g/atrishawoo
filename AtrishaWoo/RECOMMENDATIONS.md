# راهنمای استفاده از سیستم پیشنهاد محصول (AtrishaWoo Recommendation Engine)

این قابلیت سه مدل پیشنهاد محصولات مرتبط را برای ووکامرس فراهم می‌کند و می‌تواند هم به‌صورت خودکار در صفحه محصول نمایش داده شود و هم به‌صورت دستی با شورتکد داخل Elementor/قالب قرار بگیرد.

## شروع سریع (Quick Start)

1) افزونه AtrishaWoo و WooCommerce باید فعال باشند.  
2) بعد از فعال‌سازی افزونه، جداول دیتابیس لازم به‌صورت خودکار ساخته می‌شوند.  
3) اگر «نمایش خودکار» فعال باشد، در صفحه تکی محصول یک بلاک پیشنهاد محصولات نمایش داده می‌شود.

## نمایش محصولات پیشنهادی در صفحه محصول (بدون Elementor)

به‌صورت پیش‌فرض، بلاک پیشنهادها در `woocommerce_after_single_product_summary` با priority=15 اضافه می‌شود.

اگر در صفحه محصول چیزی نمایش داده نشد:
- طبیعی است تا زمانی که داده کافی جمع نشود (بازدید/خرید).
- اگر فروشگاه تازه راه‌اندازی شده، بک‌فیل (Backfill) سفارش‌های گذشته به‌مرور دیتای اولیه را می‌سازد.

## نمایش محصولات پیشنهادی با Elementor (پیشنهادی برای کنترل جایگاه)

در Elementor از ویجت Shortcode استفاده کنید و یکی از شورتکدهای زیر را وارد کنید:

### حالت خودکار (پیشنهادی)

این حالت به‌ترتیب تلاش می‌کند از «باهم‌خرید»، «خرید بعدی»، «بازدید» داده پیدا کند:

`[atrishawoo_recommendations]`

### فقط بر اساس بازدید

`[atrishawoo_recommendations type="view" limit="8" columns="4"]`

### فقط بر اساس خریدهای بعدی

`[atrishawoo_recommendations type="after" limit="8" columns="4"]`

### فقط خریداری‌شده باهم

`[atrishawoo_recommendations type="together" limit="8" columns="4"]`

پارامترها:
- `type`: یکی از `auto | view | after | together`
- `limit`: تعداد محصول (۱ تا ۲۴)
- `columns`: تعداد ستون (۱ تا ۶)
- `title`: عنوان دلخواه (اختیاری)
- `product_id`: نمایش برای یک محصول خاص (اختیاری؛ پیش‌فرض همان محصول جاری)

## خاموش کردن نمایش خودکار (برای وقتی که فقط Elementor استفاده می‌کنید)

این قطعه را در Code Snippets یا functions.php قالب فرزند قرار دهید:

```php
add_filter('atrishawoo_reco_auto_insert', '__return_false');
```

## تغییر جایگاه نمایش خودکار (Hook/Priority)

اگر می‌خواهید همان نمایش خودکار باشد ولی جای آن عوض شود:

```php
add_filter('atrishawoo_reco_hook', function () {
	return 'woocommerce_after_single_product';
});

add_filter('atrishawoo_reco_priority', function () {
	return 20;
});
```

## تغییر تنظیمات پیش‌فرض (نوع/تعداد/ستون‌ها/عنوان)

```php
add_filter('atrishawoo_reco_default_type', function () {
	return 'auto';
});

add_filter('atrishawoo_reco_limit', function () {
	return 8;
});

add_filter('atrishawoo_reco_columns', function () {
	return 4;
});

add_filter('atrishawoo_reco_title', function ($title, $type) {
	if ($type === 'together') return 'پیشنهاد ویژه: باهم می‌خرند';
	if ($type === 'after') return 'مشتری‌ها بعداً این‌ها را هم می‌خرند';
	if ($type === 'view') return 'دیگران این‌ها را هم دیده‌اند';
	return $title;
}, 10, 2);
```

## نحوه کار سیستم (دیتا چطور ساخته می‌شود)

### ۱) پیشنهاد بر اساس بازدید (View-Based)

- وقتی کاربر صفحه یک محصول را می‌بیند، افزونه یک لیست کوتاه از محصولات اخیر همان کاربر را داخل کوکی نگه می‌دارد.
- اگر کاربر قبلاً محصول/محصولات دیگری را در همان بازه زمانی دیده باشد، برای هر «جفت محصول» امتیاز (score) ثبت می‌شود.
- نتیجه: محصولاتی که معمولاً پشت سر هم یا در یک نشست (session) دیده می‌شوند، برای هم پیشنهاد می‌شوند.

### ۲) پیشنهاد بر اساس خریدهای بعدی (Bought-After / Next Purchases)

- وقتی سفارش به وضعیت `processing` یا `completed` می‌رسد، افزونه سفارش‌های قبلی همان مشتری را پیدا می‌کند:
  - اگر کاربر لاگین باشد: با `customer_id`
  - اگر مهمان باشد: با `billing_email`
- سپس بین محصولات «خرید قبلی» و «خرید فعلی» ارتباط ایجاد می‌شود.
- نتیجه: اگر مشتری‌ها معمولاً بعد از خرید X، بعداً Y را بخرند، Y برای X پیشنهاد می‌شود.

### ۳) پیشنهاد محصولات خریداری‌شده با هم (Bought-Together)

- وقتی سفارش به `processing` یا `completed` برسد، بین تمام محصولات داخل همان سفارش زوج‌سازی انجام می‌شود و امتیازها افزایش پیدا می‌کند.
- نتیجه: لوازم جانبی/تکمیل‌کننده‌هایی که معمولاً در یک سفارش کنار هم می‌آیند پیشنهاد می‌شوند.

### بک‌فیل سفارش‌های گذشته (ساخت دیتای اولیه)

افزونه یک کران ساعتی اجرا می‌کند که سفارش‌های قدیمی `processing/completed` را به‌صورت دسته‌ای پردازش می‌کند تا دیتای اولیه ساخته شود.
نکته: WP-Cron وابسته به بازدید سایت است؛ اگر سایت کم‌ترافیک باشد، این روند کندتر پیش می‌رود.

## دیتابیس و جداول

سه جدول با پیشوند دیتابیس وردپرس ساخته می‌شود:
- `{prefix}atrishawoo_reco_view`
- `{prefix}atrishawoo_reco_together`
- `{prefix}atrishawoo_reco_after`

هر جدول ساختار `product_id + related_id + score + updated_at` دارد.

## نکات سازگاری (Woodmart / Elementor / WooCommerce)

- خروجی محصولات با لوپ استاندارد ووکامرس رندر می‌شود (همان کارت محصول قالب).
- با Elementor بهترین روش استفاده از شورتکد است تا دقیقاً هرجا خواستید قرار بگیرد.

## نکات امنیت/پایداری

- هیچ داده حساس کاربر ذخیره نمی‌شود؛ فقط ارتباط بین محصولات و امتیازها ثبت می‌شود.
- برای جلوگیری از دوباره‌کاری، روی هر سفارش دو متا ذخیره می‌شود:
  - `_atrishawoo_reco_together_done`
  - `_atrishawoo_reco_after_done`

## خطایابی سریع

- اگر چیزی نمایش داده نمی‌شود: طبیعی است وقتی هنوز داده کافی ندارید.
- اگر فقط می‌خواهید با Elementor نمایش دهید: `atrishawoo_reco_auto_insert` را false کنید.
- اگر با کش/CDN مشکل کوکی دارید: پیشنهادهای نوع `view` ممکن است کمتر داده بسازد؛ از `together/after` استفاده کنید.
